# Compact Page is a Catalog budget, not an MCP courtesy

Agents waste tokens when a tool repeats full UNC paths, extra metadata, and the same list as prose. Humans still want absolute paths.

Default and maximum page is 200. Hits include rel, kind, ext, size, mtime, and owner so filters are visible. Full View adds the absolute path. Serialized budget is 128 KiB. Adapters do not re-dump hits as text. Sort is mtime newest-first; fuzzy score is not the default order.

**Status**: accepted

**Considered Options**: Let MCP truncate ad hoc; return Full always; stream hits.

**Consequences**: One test surface for token budget. Changing Compact fields is a contract change, not a handler tweak.
